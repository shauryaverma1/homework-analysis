# Mori — Your Little Study World

A gentle, anime-cottagecore study dashboard built with Next.js, TypeScript, MongoDB and Motion.

See `SETUP.md` for local development, MongoDB Atlas and Vercel deployment instructions.

## Features
- Study dashboard and task planner
- Notes notebook
- AI-assisted flashcard generation (OpenAI key optional; local fallback included)
- Focus timer and study session logging
- Progress garden and a personal letter page

## Environment
Copy `.env.example` to `.env.local` and configure `MONGODB_URI`, `MONGODB_DB`, and `MORI_ACCESS_TOKEN`. Never commit secrets.
